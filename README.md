# Portfolio Mercia

## Structure du dossier

```
Portfolio Mercia/
│
├── index.html          → Page d'accueil
├── apropos.html        → Page À propos (parcours, compétences)
├── projets.html        → Galerie de tous les projets
├── contact.html        → Page de contact
│
├── css/
│   ├── style.css       → Styles globaux (navigation, footer, typo, couleurs)
│   ├── accueil.css     → Styles spécifiques à l'accueil
│   ├── apropos.css     → Styles spécifiques à propos
│   ├── projets.css     → Styles spécifiques projets
│   └── contact.css     → Styles spécifiques contact
│
├── js/
│   └── main.js         → JavaScript (menu mobile, filtres, animations)
│
├── assets/
│   ├── images/
│   │   ├── projets/    → Screenshots et visuels des projets
│   │   ├── logos/      → Tes créations de logos
│   │   └── profil/     → Ta photo de profil
│   ├── icons/          → Icônes personnalisées
│   └── cv/
│       └── cv.pdf      → Ton CV téléchargeable
│
└── projets/
    └── template-projet.html → Modèle pour pages projet détaillées
```

## Catégories de projets

- UI/UX Design (maquettes Figma)
- Sites Web (WordPress)
- Branding & Logos (Illustrator)
- Marketing (PESTEL, SWOT, Chiffrages)
- Print & Édition (InDesign)
- Vidéo (Premiere Pro)
- Retouche photo (Photoshop)

## Pour commencer

1. Ouvrir ce dossier dans Visual Studio Code
2. Installer l'extension "Live Server" pour prévisualiser
3. Commencer par style.css (styles globaux)
4. Puis compléter page par page
